# คู่มือเปิดให้บริการบน Fastwork & แผนต่อยอดระบบอัตโนมัติ (Zero-to-Low Cost Roadmap)

> เอกสารฉบับนี้รวบรวมแนวทางปฏิบัติทีละขั้นสำหรับระบบ **เซียมซีทาโรต์ (SiamSi Tarot • Oracle)** โดยเริ่มจาก **Phase 1: เปิดร้านบน Fastwork ให้เกิดรายได้ทันทีด้วยต้นทุน 0 บาท** แล้วค่อยต่อยอดไปสู่ **ระบบ Self-Service Auto 24 ชม. + การรับโฆษณา + การตลาดต้นทุนต่ำ**

---

## Phase 1: เปิดให้บริการบน Fastwork ทันที (ต้นทุน 0 บาท)

ระบบปัจจุบันออกแบบมาให้คุณทำงานเป็น **One-Person Shop** โดยไม่ต้องพิมพ์คำทำนายเองทีละคน:

### ขั้นตอนส่งงานบน Fastwork
1. ลูกค้าสั่งซื้อแพ็กเกจใน Fastwork และชำระเงินเข้าระบบ Fastwork
2. เปิดหน้าหลังบ้าน **[admin.html](https://taro-card-smoky.vercel.app/admin.html)** เลือกแพ็กเกจให้ตรงกับออเดอร์:
   - **แพ็กเกจ 1 — ดูดวงไพ่ทาโรต์ 3 ใบ (1 ครั้ง)**: เลือกเปิดอิสระหรือกำหนด `🎯 หมวดหมู่คำทำนาย` (ความรัก / การงาน / การเงิน / สุขภาพ)
   - **แพ็กเกจ 2 — เสี่ยงเซียมซีศักดิ์สิทธิ์ (1 ครั้ง)**: ลูกค้าเลือกตำราได้เองทั้ง *หว่องไทซิน* และ *หลวงพ่อทันใจ*
   - **แพ็กเกจ 3 — แพ็กเกจเหมา 3 ศาสตร์ (ดูครบทุกศาสตร์ ศาสตร์ละ 1 ครั้ง)**: ไพ่ทาโรต์ 3 ใบ + เสี่ยงเซียมซี + สแกนลายมือ 2 ข้าง ครบในลิงก์เดียว (อายุ 24 ชม.)
   - **แพ็กเกจ 4 — สแกนดูลายมืออัจฉริยะ 2 มือ (1 ครั้ง)**
3. กด **"สร้างโค้ด"** แล้วคัดลอกข้อความสำเร็จรูป + ลิงก์ส่งให้ลูกค้าในแชท Fastwork
4. ลิงก์ที่สร้างจะมีพารามิเตอร์ `?openExternalBrowser=1` และกลไกบังคับเปิด Safari/Chrome ในตัว หากลูกค้าเปิดผ่าน LINE/FB กล้องสแกนลายมือจะไม่สะดุด

### แนวทางตั้งราคาแนะนำบน Fastwork (กลยุทธ์ Anchoring ให้ลูกค้าเลือกแพ็กเหมา)
- **แพ็กเกจ 1 (ไพ่ทาโรต์ 3 ใบ เฉพาะด้าน)** หรือ **แพ็กเกจ 2 (เซียมซี)**: ตั้งเป็นตัวเริ่มต้นเข้าถึงง่าย *(เช่น 59–79 บ. หรือตามราคาขั้นต่ำหมวดดูดวงของ Fastwork)*
- **แพ็กเกจ 4 (สแกนลายมือ 2 มือ)**: 99–149 บ.
- **แพ็กเกจ 3 (เหมา 3 ศาสตร์ ศาสตร์ละ 1 ครั้ง — Hero Package)**: ตั้งราคาต่ำกว่าผลรวมแยกซื้อ 30%–40% *(เช่น 149–199 บ. จากราคารวมแยก 260+ บ.)* เพื่อให้ลูกค้าส่วนใหญ่อัปเกรดเป็นแพ็กเหมา

### ข้อความพร้อมก๊อปลงประกาศ Fastwork (ปรับแต่งราคา/ชื่อร้านได้ทันที)

#### 1) ชื่องาน (Gig Title — กระชับและติดคำค้น)
> ดูดวงออนไลน์ 3 ศาสตร์ ไพ่ทาโรต์ • เซียมซี • สแกนลายมือ 2 มือ ทำนายได้ด้วยตนเองทันที 24 ชม.

#### 2) รายละเอียดบริการ (Service Description)
> ✨ เปิดดวงชะตาครบวงจรในรูปแบบ Interactive Oracle ทันสมัย — คุณเป็นคนตั้งจิต สับไพ่ เขย่าเซียมซี และสแกนฝ่ามือด้วยตนเอง!
>
> **แพ็กเกจบริการให้เลือก:**
> 1. 🔮 **ไพ่ทาโรต์ 3 ใบ** (เจาะลึกเฉพาะด้าน: ความรัก โสด/มีคู่ • การงาน • การเงิน • สุขภาพ)
> 2. 🎋 **เสี่ยงเซียมซีศักดิ์สิทธิ์** (เลือกได้ทั้งตำราหว่องไทซิน & หลวงพ่อทันใจ คำทำนาย 7 ด้านครบจบ)
> 3. ✋ **สแกนลายมืออัจฉริยะ 2 ข้าง (ซ้าย+ขวา)** วิเคราะห์เส้นหลักและเนินบนฝ่ามือด้วยระบบภาพดิจิทัลพร้อมคำแนะนำชีวิต
> 4. 🌟 **แพ็กเกจเหมา 3 ศาสตร์ (คุ้มที่สุด!)** ใช้สิทธิ์ครบทั้ง **ไพ่ทาโรต์ + เซียมซี + สแกนลายมือ ศาสตร์ละ 1 ครั้ง**
>
> **สิ่งที่ลูกค้าจะได้รับทันทีหลังทำรายการ:**
> - 🔑 ลิงก์ส่วนตัว + รหัสสิทธิ์ใช้งาน 24 ชั่วโมง (กดเปิดดูย้อนหลังได้ตลอดภายในเวลา)
> - 🖼️ **ภาพ Info Card 1 หน้าความละเอียดสูง (.PNG)** สวยงาม แชร์ลงโซเชียลได้ทันที
> - 📄 **เอกสารสรุปคำทำนายฉบับเต็ม (.PDF)** และข้อความพร้อม **กดปุ่มคัดลอกไปถามต่อใน Gemini** ได้เลย
>
> ⚠️ *หมายเหตุสำหรับสแกนลายมือ: กรุณาเปิดลิงก์ด้วยเบราว์เซอร์ Safari (iPhone) หรือ Chrome (Android) เพื่อใช้งานกล้องถ่ายรูป (คำพยากรณ์จัดทำเพื่อเป็นแนวทางวางแผนชีวิตและกำลังใจอย่างมีสติ)*

#### 3) ขั้นตอนการทำงาน (Work Steps)
1. กดสั่งซื้อและเลือกแพ็กเกจที่ต้องการ *(กรณีไพ่ทาโรต์แจ้งด้านที่อยากเน้นได้)*
2. ผู้ขายส่งลิงก์เข้าแท่นพยากรณ์ส่วนตัว + รหัสสิทธิ์ให้ทางแชท Fastwork
3. ลูกค้าคลิกลิงก์เพื่อตั้งจิต สับไพ่ / เขย่าเซียมซี / สแกนลายมือด้วยตนเอง *(รับผลคำทำนายทันที ไม่ต้องรอคิว)*
4. ดาวน์โหลดภาพ Info Card (.PNG) หรือ PDF เก็บไว้ได้เลยและกดยืนยันส่งมอบงาน

## Phase 2: ต่อยอดสู่ช่องทาง Self-Service Auto (เพจ + เว็บ + แอป PWA + LINE OA)

เมื่อเริ่มมีลูกค้าจาก Fastwork และต้องการดึงคนเข้ามา **ซื้อ-ดูเองอัตโนมัติ 24 ชม.** โดยไม่ต้องสร้างแอป Native เสียค่าธรรมเนียม App Store:

1. **อัปเกรดเว็บเป็น PWA (Progressive Web App — ต้นทุน ฿0)**
   - เพิ่มไฟล์ `manifest.json` + ไอคอนแอป ให้ลูกค้ากด *"เพิ่มลงหน้าจอหลัก"* บน iOS/Android เปิดใช้งานเต็มจอเหมือนแอปจริง ไม่เสียค่า Apple (`$99`/ปี) หรือ Google Play (`$25`)
2. **Facebook Page + TikTok Bio (Auto Greeting Funnel)**
   - ตั้ง Auto-Reply ใน Inbox เพจว่า *"หากต้องการดูดวงอัตโนมัติ 24 ชม. ไม่ต้องรอแอดมิน กดเลือกบริการได้ทันทีที่นี่..."* พร้อมลิงก์
3. **LINE OA (ฟรีแพ็กเกจเริ่มต้น)**
   - ตั้ง Rich Menu 3–4 ช่อง (ลองฟรี / ซื้อแพ็กเหมา 3 ศาสตร์ / เข้าด้วยรหัสเดิม / ติดต่อแอดมิน) โดยทุกปุ่มที่เชื่อมไปสแกนลายมือให้แนบ `?openExternalBrowser=1` เสมอ

### Flow แนะนำสำหรับหน้า Self-Service (Freemium → Paid)
- **ขั้นที่ 1 (ตัวดึงคนฟรี)**: ให้ลอง *"เสี่ยงเซียมซี 1 ใบ" หรือ "ไพ่ประจำวัน 1 ใบ"* ฟรี (จำกัดวันละ 1 ครั้ง)
- **ขั้นที่ 2 (เลือกแพ็กเกจเอง)**: ปุ่มอัปเกรด *"ไพ่ 3 ใบเจาะลึก / สแกนลายมือ / เหมา 3 ศาสตร์"*
- **ขั้นที่ 3 (ออกรหัสอัตโนมัติ)**: หลังจ่ายเงินสำเร็จ Supabase Edge Function `taro-api` สร้างแถวใหม่ใน `taro_codes` ให้ทันที แล้ว Redirect ลูกค้าเข้าหน้าดูดวงอัตโนมัติใน 2 วินาที

## Phase 3: ระบบชำระเงินอัตโนมัติ (Zero-to-Low Cost)

| แนวทาง | กลไกการทำงาน | จุดเด่น / ต้นทุน (โดยประมาณ*) |
| :--- | :--- | :--- |
| **A. PromptPay QR + ตรวจสลิปอัตโนมัติ** *(แนะนำเริ่มตัวนี้)* | หน้าเว็บสร้าง QR PromptPay ยอดเงินตรงแพ็กเกจ → ลูกค้าโอนแล้วอัปโหลดสลิป → Supabase Edge Function ส่งตรวจ Slip Verification API (เช็กชื่อบัญชี, ยอดโอน, และเลข `transRef` ลงตาราง `used_slips` กันใช้สลิปซ้ำ) → ออกรหัสโค้ดทันที | ค่าธรรมเนียมรับเงิน **0%** เสียเฉพาะค่าตรวจสลิป API (~0.25–0.60 บ./รายการ หรือแพ็กฟรีรายเดือน) เงินเข้าบัญชีตรงทันที |
| **B. Payment Gateway Webhook** *(Omise / Stripe Thailand / ChillPay)* | ลูกค้าสแกน PromptPay / จ่ายบัตร → Gateway ยิง Webhook มาที่ `taro-api` → ปลดล็อกโค้ดให้ทันที **ไม่ต้องอัปโหลดสลิป** | สะดวกที่สุดเมื่อยอดขายสูงขึ้น (ค่าธรรมเนียม PromptPay ~1.5–1.8%, บัตร ~3.65%) |

## Phase 4: การหารายได้, รับลงโฆษณา และตลาดต้นทุน 0 บาท

### แหล่งรายได้เสริมบนเว็บ
1. **Google AdSense เฉพาะหน้าเล่นฟรี**: ใส่โฆษณาเฉพาะหน้าฟรี (เซียมซีฟรี / สารานุกรมความหมายไพ่) — **งดใส่ในหน้าลูกค้าจ่ายเงิน** เพื่อรักษาประสบการณ์พรีเมียม
2. **Direct Sponsorship (รับลงแบนเนอร์สายมูตรง)**: เหมารายสัปดาห์/รายเดือนให้ร้านหินมงคล วอลเปเปอร์เสริมดวง ร้านธูปเทียน หรือสำนักดูดวงส่วนตัว (Margin สูงกว่าค่าคลิก AdSense ในช่วงที่ทราฟฟิกยังไม่ถึงหลักแสน)
3. **Affiliate สายมู (ต้นทุน ฿0)**: วางลิงก์แนะนำของ Shopee/Lazada ท้ายหน้าผลทำนายฟรีตามหัวข้อ (เช่น กระเป๋าสตางค์สีมงคล, ของแก้ปีชง)
4. **High-Ticket Upsell**: หลังดู AI อัตโนมัติจบ เพิ่มปุ่ม *"จองคิวคุยกับหมอดูตัวจริง 20–30 นาที"* (ราคา 299–599 บ.)

### กลยุทธ์การตลาดต้นทุน 0 – ต่ำ
1. **Viral Info Card Watermark (ได้ผลสูงสุดกับระบบที่มีอยู่)**: เติมชื่อเว็บหรือ QR Code ขนาดเล็กที่มุมล่างของ Info Card 1 หน้า ทุกครั้งที่ลูกค้าเซฟภาพไปโพสต์ลง IG Story / Facebook / X จะช่วยแนะนำลูกค้าใหม่กลับมาสแกนฟรีอัตโนมัติ
2. **Short-Form Video (TikTok / Reels / YouTube Shorts)**: อัดคลิป 15–30 วินาทีโชว์หน้าจอสแกนลายมือ 2 ข้างจริง หรือคลิป *"เช็กคำทำนายหลวงพ่อทันใจสัปดาห์นี้"* แล้วปักลิงก์ Bio
3. **SEO เนื้อหาสาธารณะ**: มีฐานข้อมูลเซียมซีครบ 200 ใบ + ไพ่ 78 ใบอยู่แล้ว สามารถเปิดหน้าสารานุกรมให้ Google ค้นเจอคำค้นหาไทยรายวัน พร้อมปุ่มชวนทดลองเปิดดวงฟรี
4. **คำแนะนำด้านนโยบายโฆษณา**: หากอนาคตยิงแอดบน Meta/TikTok/Google ให้สื่อสารด้วยภาษาที่ปลอดภัย เช่น *"วิเคราะห์ลายมือและไพ่ด้วย AI เพื่อเป็นแนวทางพัฒนาตนเองและความบันเทิง"* หลีกเลี่ยงคำเคลมเกินจริง เช่น "รวย 100%" หรือ "แก้กรรมเห็นผลทันที" เพื่อป้องกันบัญชีโฆษณาถูกระงับ
