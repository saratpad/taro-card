# 🔮 Mystic Witch Tarot (แม่มดพยากรณ์ ไพ่ทาโรต์)

เว็บแอปพลิเคชันดูดวงไพ่ทาโรต์ครบชุด 78 ใบ (Major Arcana & Minor Arcana) สไตล์แม่มดมนตรา รองรับ Responsive Design ทุกขนาดหน้าจอ ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์ รองรับ 2 ภาษา (ไทย / อังกฤษ) พร้อมระบบเชื่อมต่อ **Gemini AI 1-Click Consultation**

## ✨ จุดเด่นของระบบ (Features)

1. **ไพ่ทาโรต์ครบทั้ง 78 ใบ (Rider-Waite Deck)**
   - ภาพคมชัดขนาดต้นฉบับ จากแหล่งอ้างอิง [Shitsuren Tarot](https://www.shitsuren-tarot.com/tarot/)
   - ครบทั้ง 22 ใบ Major Arcana และ 56 ใบ Minor Arcana (เหรียญ, ถ้วย, ดาบ, ไม้)
   - รองรับทั้งความหมายไพ่ตั้งตรง (Upright) และไพ่กลับหัว (Reversed)

2. **Flow การดูดวงที่ตรงตามตำราศาสตร์ไพ่ทาโรต์**
   - **เลือกหมวดหมู่ที่สนใจ**: ความรัก (Love), การงาน (Career), การเงิน (Finance), สุขภาพ (Health), และทั่วไป/ตัดสินใจ (General)
   - **เลือกรูปแบบการวางไพ่ (Spread)**:
     - 🎴 1 ใบ: คำตอบด่วน หรือไพ่ประจำวัน
     - 🎴 3 ใบ: อดีต • ปัจจุบัน • อนาคต
     - 🎴 4 ใบ: เจาะลึกหาสาเหตุและแนวทางแก้ไขปัญหา
     - 🎴 5 ใบ: ภาพรวมและทิศทางชีวิต
   - แอนิเมชันสำรับไพ่คลี่เป็นพัด 3D พร้อมระบบสุ่มไพ่แบบสลับตำแหน่งและมีโอกาสออกไพ่กลับหัวตามหลักสถิติ

3. **บทวิเคราะห์คำทำนายและข้อคิดเตือนใจ**
   - บทสรุปภาพรวมดวงชะตาตามตำรา (Traditional Tarot Synthesis)
   - ฟันธงแนวโน้ม: เป็นบวกมาก / ปานกลาง / ควรระวังและเตรียมพร้อม
   - สรุปสิ่งที่ควรทำ (Do's) และสิ่งที่ไม่ควรทำ / ข้อควรระวัง (Don'ts)
   - ไพ่ 3D พลิกเปิดการ์ดทีละใบ พร้อมคำทำนายเฉพาะตำแหน่งและสารเตือนใจจากแม่มด

4. **ระบบ 1-Click Gemini AI Integration**
   - มีช่องสำหรับกรอกคำถามเฉพาะเจาะจงเพิ่มเติมที่ด้านล่างสุดของหน้าผลลัพธ์
   - พรีวิว Prompt แบบเรียลไทม์ที่ประกอบด้วยคำถาม, หมวดหมู่, ไพ่ทุกใบที่เปิดได้, ตำแหน่ง, และคำแนะนำตามตำรา
   - ปุ่ม **"🚀 คัดลอกคำถาม+คำทำนาย & เข้าสู่ Gemini ทันที (แค่กดวาง)"**: ก๊อบปี้ข้อมูลลงคลิปบอร์ดและเปิด `https://gemini.google.com/app` ให้อัตโนมัติทันที ผู้ใช้เพียงกดวาง (Ctrl+V / Cmd+V) เพื่อเริ่มสนทนากับ AI ได้ทันที

5. **คลังคัมภีร์ไพ่ 78 ใบ (Tarot Grimoire)**
   - ค้นหาชื่อไพ่ คีย์เวิร์ด และกรองตามชุดไพ่ (Major, เหรียญ, ถ้วย, ดาบ, ไม้)
   - คลิกเพื่อดูรายละเอียด ธาตุประจำไพ่ ความหมายเฉพาะด้าน และคำแนะนำจากแม่มด

6. **ระบบเสียงจำลองบรรยากาศ (Mystic Audio Engine)**
   - สร้างเสียงจำลองบรรยากาศ (Web Audio API) ทั้งเสียงสับไพ่ เสียงเปิดไพ่ 3D และเสียงกระดิ่งคริสตัล

## 🚀 วิธีการติดตั้งและรันใช้งาน (Getting Started)

โครงสร้างโปรเจกต์เป็น Client-side Web App 100% ไม่จำเป็นต้องติดตั้ง dependencies ภายนอก:

```bash
# Clone repository
git clone https://github.com/saratpad/taro-card.git
cd taro-card

# เปิดใช้งานผ่านเว็บเบราว์เซอร์
# วิธีที่ 1: ดับเบิลคลิกเปิดไฟล์ index.html ในเบราว์เซอร์ได้ทันที
# วิธีที่ 2: รัน Local Server ด้วย Python
python3 -m http.server 3000
```
เปิดเบราว์เซอร์แล้วไปที่ `http://localhost:3000`
