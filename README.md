# 🔮 เซียมซีทาโรต์ (SiamSi Tarot) — ระบบพยากรณ์ไพ่ทาโรต์ 3 ใบ & เสี่ยงเซียมซี สำหรับรับงาน Fastwork

ระบบเว็บแอปพลิเคชันดูดวง **ไพ่ทาโรต์ 3 ใบ (Rider-Waite 78 Cards)** และ **เสี่ยงเซียมซีศักดิ์สิทธิ์ 100 ใบ** พร้อม **ระบบหลังบ้าน (Admin Backoffice)** สำหรับสร้างโค้ดให้ลูกค้าในแพลตฟอร์ม **Fastwork**

---

## ✨ ฟีเจอร์หลักที่พัฒนาเพื่อการรับงาน Fastwork

### 1. ระบบหลังบ้านจัดการโค้ดและติดตาม Log (`admin.html`)
- **สร้างและจัดการรหัสโค้ด (Access Code)**:
  - กำหนดสิทธิ์เข้าถึงแยกชัดเจนระหว่าง **🔮 ไพ่ทาโรต์ 3 ใบ** หรือ **🎋 เสี่ยงเซียมซี**
  - โค้ดจำกัดสิทธิ์การสุ่มเปิดดวง **1 ครั้ง** และมีอายุใช้งาน **1 วัน (24 ชั่วโมง)**
  - มีปุ่ม **คัดลอกข้อความสำเร็จรูปพร้อมลิงก์เข้าดูดวงอัตโนมัติ (`?code=XXXX`)** สำหรับส่งให้ลูกค้าในแชท Fastwork ได้ทันที
- **ระบบ Log ติดตามสถานะลูกค้าแบบละเอียด**:
  - 👁️ ลูกค้าเข้าระบบหรือยัง (เข้าเมื่อไหร่ / กี่ครั้ง)
  - 🎴 สุ่มจับไพ่/เซียมซีหรือยัง (แสดงชื่อไพ่ทั้ง 3 ใบ หรือเบอร์เซียมซีที่ลูกค้าสุ่มได้ทันที)
  - 📤 กดแชร์โซเชียลหรือยัง
  - 📄 กดดาวน์โหลดไฟล์ PDF หรือยัง
- **เครื่องมือส่งงานแบบแมนนวลสำหรับแอดมิน (Manual Fulfillment)**:
  - **📄 โหลด PDF คำทำนาย**: ดาวน์โหลดไฟล์ `.pdf` คำทำนายของลูกค้ารายนั้นจากหลังบ้านเพื่อส่งให้ในแชท Fastwork ได้โดยตรง
  - **🖼️ โหลดรูป Info Card**: ดาวน์โหลดภาพสรุปหน้าไพ่ 3 ใบพร้อมคำทำนายย่อ (`.png`)
  - **🎲 สุ่มทำนายให้ลูกค้าทันที**: กรณีลูกค้าให้หมอดูสุ่มให้แล้วส่งไฟล์ PDF ให้
  - **🔄 รีเซ็ตสิทธิ์ 1 ครั้ง** / **⏳ ต่ออายุ +1 วัน** / **🗑️ ลบโค้ด**

### 2. ระบบดูดวงหน้าร้านสำหรับลูกค้า (`index.html`)
- **UX/UI มืออาชีพ รองรับมือถือเป็นหลัก (Mobile-First) และแยกเมนูเด็ดขาด**:
  - เมื่อเข้าด้วยโค้ด **ไพ่ทาโรต์** จะแสดงเฉพาะระบบไพ่ทาโรต์ 3 ใบ (ไม่แสดงเมนูเซียมซีให้สับสน)
  - เมื่อเข้าด้วยโค้ด **เสี่ยงเซียมซี** จะแสดงเฉพาะระบบเขย่าเซียมซี (ไม่แสดงเมนูไพ่ทาโรต์)
- **พยากรณ์ไพ่ทาโรต์ 3 ใบ**:
  - ล็อกรูปแบบการดูไพ่ **3 ใบ** ที่ทรงพลังและเข้าใจง่าย
  - เลือกหมวดหมู่เฉพาะด้าน **4 หมวดหลัก** (💖 ความรัก, 💼 การงาน, 💰 การเงิน, 🌿 สุขภาพ — ตัดหมวดทั่วไปออก)
  - พื้นหลังเคลื่อนไหวสุดขลัง (วงเวทย์จักรวาลหมุนช้าๆ + เงาไพ่ทาโรต์และไม้ติ้วเซียมซีโบราณลอยเคลื่อนไหว + ละอองดาวทองคำ)
  - เอฟเฟกต์ตอนสับไพ่ หยิบไพ่ (เสาแสงทองคำและอักษรรูน) และฉากเปิดไพ่ 3D พร้อมคลื่นวงแหวนมนตรา
  - คำทำนายกระชับ ชัดเจน ตรงหมวดหมู่ที่เลือก ไม่อธิบายซ้ำหลายรอบ
- **แชร์โซเชียล (Info Card + คำทำนายเต็ม) & ดาวน์โหลดไฟล์ PDF**:
  - สร้างภาพ **Info Card** ที่มีรูปไพ่ทั้ง 3 ใบที่จับได้จริง + คำทำนายด้านที่เลือกอย่างย่ออยู่ในภาพ
  - พร้อมกล่อง **คำทำนายฉบับเต็ม** สำหรับวางต่อท้ายเป็นโพสต์หรือคอมเมนต์
  - ปุ่มดาวน์โหลดใบคำทำนายเก็บลงเครื่องเป็นไฟล์ **`.pdf` แท้** ได้ทันที

## 🚀 วิธีรันใช้งานระบบ

### วิธีที่ 1: รันผ่าน Node.js Server (แนะนำ — ซิงค์ข้อมูลโค้ดและ Log ลงฐานข้อมูล `data/codes-db.json`)
```bash
node server.js
```
- **หน้าดูดวงสำหรับลูกค้า**: `http://localhost:3000`
- **หน้าจัดการหลังบ้าน (Admin Backoffice)**: `http://localhost:3000/admin.html`

### วิธีที่ 2: เปิดไฟล์โดยตรงบนเบราว์เซอร์ (Static / Local Mode)
- สามารถเปิด `index.html` และ `admin.html` บนเบราว์เซอร์เดียวกันได้ทันที ระบบจะซิงค์ข้อมูลผ่าน `localStorage` อัตโนมัติ
